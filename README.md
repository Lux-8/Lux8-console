# Lux8-console

Модульная CLI-утилита на чистом Python, имитирующая работу защищённой операционной консоли с криптографической авторизацией.

## Основные возможности

- **Криптографическая защита паролей:** пароли не хранятся в открытом виде — используется алгоритм `PBKDF2-HMAC-SHA256` (100 000 итераций) с генерацией уникальной криптографической «соли» (`os.urandom`) в формате `salt:hash`.
- **Доступ суперпользователя:** встроенная учётная запись `root` со звёздочкой `*` в качестве ключа доступа и подтверждением входа в интерактивную среду.
- **Модульная архитектура:** логика разделена на независимые компоненты для удобной поддержки и расширения.
- **Нулевые внешние зависимости:** проект написан исключительно на стандартной библиотеке Python (`hashlib`, `os`).

## Архитектура проекта

- `main.py` — точка входа, последовательно запускает процесс авторизации и передаёт управление в консоль.
- `security.py` — модуль безопасности: генерация хешей с солью (`make_hash`), ввод учётных данных и верификация пароля (`check_keys`).
- `console.py` — интерфейс командной оболочки, проверка прав доступа и меню доступных команд (`quit`, `new_user`, `set_pass`).
- `requirements.txt` — спецификация окружения (внешние пакеты не требуются).

## Запуск

1. Клонируйте репозиторий и перейдите в папку проекта:
   ```bash
   git clone https://github.com
   cd Lux8-console
   ```

2. Запустите главный файл (требуется Python 3.10+):
   ```bash
   python main.py
   ```

3. Для входа используйте учётные данные по умолчанию:
   - **Логин:** `root`
   - **Пароль:** `*`
